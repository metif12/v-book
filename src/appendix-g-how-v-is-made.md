# Appendix G: How V is Made

V is an open-source project. The compiler is written in V itself.

## Repository

- GitHub: [vlang/v](https://github.com/vlang/v)
- License: MIT

## Building from source

```bash
git clone https://github.com/vlang/v
cd v
make
```
