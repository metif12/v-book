# अपेंडिक्स B: ऑपरेटर

## अंकगणित

| ऑपरेटर | विवरण |
|----------|-------------|
| `+` | जोड़ |
| `-` | घटाव |
| `*` | गुणा |
| `/` | भाग |
| `%` | मोड्युलो |
| `**` | घात |

## तुलना

| ऑपरेटर | विवरण |
|----------|-------------|
| `==` | बराबर |
| `!=` | बराबर नहीं |
| `<` | से कम |
| `>` | से अधिक |
| `<=` | से कम या बराबर |
| `>=` | से अधिक या बराबर |

## तार्किक

| ऑपरेटर | विवरण |
|----------|-------------|
| `&&` | तार्किक AND |
| `\|\|` | तार्किक OR |
| `!` | तार्किक NOT |

## बिटवाइज़

| ऑपरेटर | विवरण |
|----------|-------------|
| `&` | बिटवाइज़ AND |
| `\|` | बिटवाइज़ OR |
| `^` | बिटवाइज़ XOR |
| `<<` | लेफ्ट शिफ्ट |
| `>>` | राइट शिफ्ट |

## असाइनमेंट

| ऑपरेटर | विवरण |
|----------|-------------|
| `=` | असाइनमेंट |
| `:=` | शॉर्ट घोषणा |
| `+=` | जोड़ें और असाइन करें |
| `-=` | घटाएं और असाइन करें |
| `*=` | गुणा करें और असाइन करें |
| `/=` | भाग करें और असाइन करें |
| `%=` | मोड्युलो करें और असाइन करें |
