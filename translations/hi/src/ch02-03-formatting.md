# v fmt के साथ फॉर्मेटिंग

V में एक बिल्ट-इन कोड फॉर्मेटर है:

```bash
v fmt -w .
```

`-w` फ़्लैग परिवर्तनों को वापस फ़ाइलों में लिखता है। इसके बिना, फॉर्मेटर stdout पर प्रिंट करता है।

## उदाहरण

पहले:

```v
fn main(){
println( 'hello' )
}
```

`v fmt` के बाद:

```v
fn main() {
    println('hello')
}
```
