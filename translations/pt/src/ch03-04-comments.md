# Comentários

## Comentários de linha

```v
// This is a line comment
x := 42 // Comment after code
```

## Comentários de bloco

```v
/* This is a
   block comment */
```

## Comentários de documentação

```v
// add returns the sum of a and b.
fn add(a int, b int) int {
    return a + b
}
```
