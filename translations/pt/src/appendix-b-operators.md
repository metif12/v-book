# Apêndice B: Operadores

## Aritméticos

| Operador | Descrição |
|----------|-------------|
| `+` | Adição |
| `-` | Subtração |
| `*` | Multiplicação |
| `/` | Divisão |
| `%` | Módulo |
| `**` | Potência |

## Comparação

| Operador | Descrição |
|----------|-------------|
| `==` | Igual |
| `!=` | Diferente |
| `<` | Menor que |
| `>` | Maior que |
| `<=` | Menor ou igual |
| `>=` | Maior ou igual |

## Lógicos

| Operador | Descrição |
|----------|-------------|
| `&&` | E lógico |
| `\|\|` | OU lógico |
| `!` | NÃO lógico |

## Bit a bit

| Operador | Descrição |
|----------|-------------|
| `&` | E bit a bit |
| `\|` | OU bit a bit |
| `^` | XOR bit a bit |
| `<<` | Deslocamento à esquerda |
| `>>` | Deslocamento à direita |

## Atribuição

| Operador | Descrição |
|----------|-------------|
| `=` | Atribuição |
| `:=` | Declaração curta |
| `+=` | Somar e atribuir |
| `-=` | Subtrair e atribuir |
| `*=` | Multiplicar e atribuir |
| `/=` | Dividir e atribuir |
| `%=` | Módulo e atribuir |
