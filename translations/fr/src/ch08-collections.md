# Chapitre 8 : Collections

## Tableaux

```v
fn main() {
    mut nums := [1, 2, 3]
    nums << 4
    println(nums)
    println(nums.len)
    println(nums[0])
}
```

## Maps

```v
fn main() {
    mut ages := {
        'Alice': 30
        'Bob':   25
    }
    ages['Charlie'] = 35
    println(ages)
    println(ages['Alice'])
}
```

## Chaînes de caractères

```v
fn main() {
    s := 'Hello, World!'
    println(s.len)
    println(s[0])
    println(s.contains('World'))
    println(s.to_upper())
}
```

## Résumé

Dans ce chapitre, vous avez appris les tableaux, les maps et les chaînes de caractères. Dans le chapitre suivant, nous explorerons la gestion des erreurs.
