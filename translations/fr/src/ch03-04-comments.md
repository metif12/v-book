# Commentaires

## Commentaires de ligne

```v
// This is a line comment
x := 42 // Comment after code
```

## Commentaires de bloc

```v
/* This is a
   block comment */
```

## Commentaires de documentation

```v
// add returns the sum of a and b.
fn add(a int, b int) int {
    return a + b
}
```
