# Annexe D : Vue d'ensemble de la bibliothèque standard

La bibliothèque standard de V comprend :

| Module | Description |
|--------|-------------|
| `os` | Interface du système d'exploitation |
| `io` | Entrées/sorties |
| `strings` | Utilitaires de chaînes |
| `arrays` | Utilitaires de tableaux |
| `math` | Fonctions mathématiques |
| `time` | Heure et date |
| `json` | Encodage/décodage JSON |
| `http` | Client/serveur HTTP |
| `db` | Interface de base de données |
| `rand` | Génération de nombres aléatoires |
| `crypto` | Fonctions cryptographiques |
| `encoding` | Utilitaires d'encodage |
| `term` | Utilitaires de terminal |
| `sync` | Primitives de synchronisation |
| `v.ast` | Manipulation de l'AST V |
| `v.compiler` | Utilitaires du compilateur |
