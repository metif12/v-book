# Annexe G : Comment V est conçu

V est un projet open-source. Le compilateur est écrit en V lui-même.

## Dépôt

- GitHub : [vlang/v](https://github.com/vlang/v)
- Licence : MIT

## Compiler depuis les sources

```bash
git clone https://github.com/vlang/v
cd v
make
```
