# Annexe B : Opérateurs

## Arithmétiques

| Opérateur | Description |
|-----------|-------------|
| `+` | Addition |
| `-` | Soustraction |
| `*` | Multiplication |
| `/` | Division |
| `%` | Modulo |
| `**` | Puissance |

## Comparaison

| Opérateur | Description |
|-----------|-------------|
| `==` | Égal |
| `!=` | Différent |
| `<` | Inférieur à |
| `>` | Supérieur à |
| `<=` | Inférieur ou égal |
| `>=` | Supérieur ou égal |

## Logiques

| Opérateur | Description |
|-----------|-------------|
| `&&` | ET logique |
| `\|\|` | OU logique |
| `!` | NON logique |

## Binaires

| Opérateur | Description |
|-----------|-------------|
| `&` | ET binaire |
| `\|` | OU binaire |
| `^` | XOR binaire |
| `<<` | Décalage à gauche |
| `>>` | Décalage à droite |

## Affectation

| Opérateur | Description |
|-----------|-------------|
| `=` | Affectation |
| `:=` | Déclaration courte |
| `+=` | Addition et affectation |
| `-=` | Soustraction et affectation |
| `*=` | Multiplication et affectation |
| `/=` | Division et affectation |
| `%=` | Modulo et affectation |
