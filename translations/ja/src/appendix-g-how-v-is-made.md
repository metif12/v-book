# 付録G：Vの作られ方

Vはオープンソースプロジェクトです。コンパイラはV自身で書かれています。

## リポジトリ

- GitHub: [vlang/v](https://github.com/vlang/v)
- ライセンス: MIT

## ソースからビルド

```bash
git clone https://github.com/vlang/v
cd v
make
```
