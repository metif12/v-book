# 付録D：標準ライブラリ概要

Vの標準ライブラリには以下が含まれます：

| モジュール | 説明 |
|--------|-------------|
| `os` | オペレーティングシステムインターフェース |
| `io` | 入出力 |
| `strings` | 文字列ユーティリティ |
| `arrays` | 配列ユーティリティ |
| `math` | 数学関数 |
| `time` | 日付と時刻 |
| `json` | JSONエンコード/デコード |
| `http` | HTTPクライアント/サーバー |
| `db` | データベースインターフェース |
| `rand` | 乱数生成 |
| `crypto` | 暗号関数 |
| `encoding` | エンコーディングユーティリティ |
| `term` | ターミナルユーティリティ |
| `sync` | 同期プリミティブ |
| `v.ast` | V AST操作 |
| `v.compiler` | コンパイラユーティリティ |
