# v fmt দিয়ে ফরম্যাটিং

V-তে একটি বিল্ট-ইন কোড ফরম্যাটার আছে:

```bash
v fmt -w .
```

`-w` ফ্ল্যাগ পরিবর্তনগুলো ফাইলে ফিরিয়ে লেখে। এটি ছাড়া ফরম্যাটার stdout-এ প্রিন্ট করে।

## উদাহরণ

আগে:

```v
fn main(){
println( 'hello' )
}
```

`v fmt` এর পর:

```v
fn main() {
    println('hello')
}
```
