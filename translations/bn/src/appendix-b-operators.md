# অতিরিক্ত B: অপারেটর

## পাঙ্কিতিক

| অপারেটর | বিবরণ |
|----------|-------------|
| `+` | সংযোজন |
| `-` | বিয়োগ |
| `*` | গুণ |
| `/` | ভাগ |
| `%` | মডুলো |
| `**` | ঘাত |

## তুলনামূলক

| অপারেটর | বিবরণ |
|----------|-------------|
| `==` | সমান |
| `!=` | অসমান |
| `<` | কম |
| `>` | বেশি |
| `<=` | কম বা সমান |
| `>=` | বেশি বা সমান |

## লজিক্যাল

| অপারেটর | বিবরণ |
|----------|-------------|
| `&&` | লজিক্যাল AND |
| `\|\|` | লজিক্যাল OR |
| `!` | লজিক্যাল NOT |

## বিটওয়াইজ

| অপারেটর | বিবরণ |
|----------|-------------|
| `&` | বিটওয়াইজ AND |
| `\|` | বিটওয়াইজ OR |
| `^` | বিটওয়াইজ XOR |
| `<<` | বাম শিফট |
| `>>` | ডান শিফট |

| অপারেটর | বিবরণ |
|----------|-------------|
| `=` | অ্যাসাইনমেন্ট |
| `:=` | সংক্ষিপ্ত ঘোষণা |
| `+=` | যোগ করে অ্যাসাইন করা |
| `-=` | বিয়োগ করে অ্যাসাইন করা |
| `*=` | গুণ করে অ্যাসাইন করা |
| `/=` | ভাগ করে অ্যাসাইন করা |
| `%=` | মডুলো করে অ্যাসাইন করা |
