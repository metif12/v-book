# 부록 A: 키워드

V는 다음 키워드를 가집니다:

| 키워드 | 설명 |
|---------|-------------|
| `as` | 타입 캐스팅 |
| `assert` | 어서션 |
| `break` | 루프 탈출 |
| `const` | 상수 선언 |
| `continue` | 다음 반복으로 진행 |
| `defer` | 지연 실행 |
| `else` | else 분기 |
| `enum` | 열거형 |
| `false` | 불리언 false |
| `fn` | 함수 선언 |
| `for` | 루프 |
| `go` | 고루틴 생성 |
| `goto` | goto 문 |
| `if` | 조건문 |
| `import` | 모듈 임포트 |
| `in` | 멤버십 테스트 |
| `interface` | 인터페이스 선언 |
| `is` | 타입 체크 |
| `lock` | 뮤텍스 잠금 |
| `match` | 패턴 매칭 |
| `module` | 모듈 선언 |
| `mut` | 가변 |
| `none` | none 값 |
| `or` | 에러 처리 |
| `pub` | public 가시성 |
| `return` | 함수에서 반환 |
| `struct` | struct 선언 |
| `true` | 불리언 true |
| `type` | 타입 선언 |
| `union` | 유니온 선언 |
| `unsafe` | unsafe 코드 |
