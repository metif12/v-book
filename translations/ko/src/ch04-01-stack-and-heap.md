# 스택과 힙

V는 스택 또는 힙에 할당할지 자동으로 결정합니다:

```v
fn main() {
    // 스택 할당 (작고, 고정 크기)
    x := 42
    arr := [1, 2, 3]

    // 힙 할당 (크고, 동적)
    mut big := []int{}
    for i in 0 .. 1000 {
        big << i
    }

    println('${x} ${arr} ${big.len}')
}
```

## 스택

- 빠른 할당 및 해제
- 컴파일 타임에 고정 크기
- 스코프가 끝나면 자동으로 해제

## 힙

- 동적 크기
- 느린 할당
- GC 또는 autofree로 관리
