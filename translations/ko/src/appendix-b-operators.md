# 부록 B: 연산자

## 산술

| 연산자 | 설명 |
|----------|-------------|
| `+` | 덧셈 |
| `-` | 뺄셈 |
| `*` | 곱셈 |
| `/` | 나눗셈 |
| `%` | 나머지 |
| `**` | 거듭제곱 |

## 비교

| 연산자 | 설명 |
|----------|-------------|
| `==` | 같음 |
| `!=` | 같지 않음 |
| `<` | 미만 |
| `>` | 초과 |
| `<=` | 이하 |
| `>=` | 이상 |

## 논리

| 연산자 | 설명 |
|----------|-------------|
| `&&` | 논리 AND |
| `\|\|` | 논리 OR |
| `!` | 논리 NOT |

## 비트

| 연산자 | 설명 |
|----------|-------------|
| `&` | 비트 AND |
| `\|` | 비트 OR |
| `^` | 비트 XOR |
| `<<` | 왼쪽 시프트 |
| `>>` | 오른쪽 시프트 |

## 대입

| 연산자 | 설명 |
|----------|-------------|
| `=` | 대입 |
| `:=` | 짧은 선언 |
| `+=` | 덧셈 후 대입 |
| `-=` | 뺄셈 후 대입 |
| `*=` | 곱셈 후 대입 |
| `/=` | 나눗셈 후 대입 |
| `%=` | 나머지 후 대입 |
