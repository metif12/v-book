# 데이터 타입

## 정수 타입

| 타입 | 크기 | 범위 |
|------|------|-------|
| `i8` | 8비트 | -128 ~ 127 |
| `i16` | 16비트 | -32,768 ~ 32,767 |
| `i32` | 32비트 | -2^31 ~ 2^31-1 |
| `i64` | 64비트 | -2^63 ~ 2^63-1 |
| `int` | 플랫폼 | 일반적으로 64비트 |
| `u8` | 8비트 | 0 ~ 255 |
| `u16` | 16비트 | 0 ~ 65,535 |
| `u32` | 32비트 | 0 ~ 2^32-1 |
| `u64` | 64비트 | 0 ~ 2^64-1 |

## 부동소수점 타입

| 타입 | 크기 |
|------|------|
| `f32` | 32비트 |
| `f64` | 64비트 |

## 기타 타입

- `bool` — `true` 또는 `false`
- `string` — UTF-8 문자열
- `rune` — 단일 유니코드 문자 (`u32`의 별칭)
- `byte` — `u8`의 별칭

## 타입 변환

```v
fn main() {
    a := 42
    b := f64(a)
    c := int(b)
    println('${a} ${b} ${c}')
}
```
