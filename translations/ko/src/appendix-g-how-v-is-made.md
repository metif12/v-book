# 부록 G: V는 어떻게 만들어지는가

V는 오픈 소스 프로젝트입니다. 컴파일러는 V 자체로 작성되었습니다.

## 저장소

- GitHub: [vlang/v](https://github.com/vlang/v)
- 라이선스: MIT

## 소스에서 빌드

```bash
git clone https://github.com/vlang/v
cd v
make
```
