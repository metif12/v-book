# الملحق B: المعاملات

## حسابية

| المعامل | الوصف |
|----------|-------------|
| `+` | جمع |
| `-` | طرح |
| `*` | ضرب |
| `/` | قسمة |
| `%` | باقي القسمة |
| `**` | أس |

## مقارنة

| المعامل | الوصف |
|----------|-------------|
| `==` | يساوي |
| `!=` | لا يساوي |
| `<` | أقل من |
| `>` | أكبر من |
| `<=` | أقل من أو يساوي |
| `>=` | أكبر من أو يساوي |

## منطقية

| المعامل | الوصف |
|----------|-------------|
| `&&` | وَ منطقي |
| `\|\|` | أو منطقي |
| `!` | نفي منطقي |

## على مستوى البت

| المعامل | الوصف |
|----------|-------------|
| `&` | وَ على مستوى البت |
| `\|` | أو على مستوى البت |
| `^` | XOR على مستوى البت |
| `<<` | إزاحة لليسار |
| `>>` | إزاحة لليمين |

## إسناد

| المعامل | الوصف |
|----------|-------------|
| `=` | إسناد |
| `:=` | تعريف مختصر |
| `+=` | اجمع وأسند |
| `-=` | اطرح وأسند |
| `*=` | اضرب وأسند |
| `/=` | اقسم وأسند |
| `%=` | باقي القسمة وأسند |
