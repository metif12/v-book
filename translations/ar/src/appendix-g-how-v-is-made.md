# الملحق G: كيف يُصنع V

V هو مشروع مفتوح المصدر. المُصرِّف مكتوب بـ V نفسه.

## المستودع

- GitHub: [vlang/v](https://github.com/vlang/v)
- الترخيص: MIT

## البناء من المصدر

```bash
git clone https://github.com/vlang/v
cd v
make
```
