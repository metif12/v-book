# Anhang G: Wie V gemacht wird

V ist ein Open-Source-Projekt. Der Compiler ist selbst in V geschrieben.

## Repository

- GitHub: [vlang/v](https://github.com/vlang/v)
- Lizenz: MIT

## Aus dem Quellcode kompilieren

```bash
git clone https://github.com/vlang/v
cd v
make
```
