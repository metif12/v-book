# Anhang B: Operatoren

## Arithmetik

| Operator | Beschreibung |
|----------|-------------|
| `+` | Addition |
| `-` | Subtraktion |
| `*` | Multiplikation |
| `/` | Division |
| `%` | Modulo |
| `**` | Potenz |

## Vergleich

| Operator | Beschreibung |
|----------|-------------|
| `==` | Gleich |
| `!=` | Ungleich |
| `<` | Kleiner als |
| `>` | Größer als |
| `<=` | Kleiner oder gleich |
| `>=` | Größer oder gleich |

## Logisch

| Operator | Beschreibung |
|----------|-------------|
| `&&` | Logisches UND |
| `\|\|` | Logisches ODER |
| `!` | Logisches NICHT |

## Bitweise

| Operator | Beschreibung |
|----------|-------------|
| `&` | Bitweises UND |
| `\|` | Bitweises ODER |
| `^` | Bitweises XOR |
| `<<` | Linksverschiebung |
| `>>` | Rechtsverschiebung |

## Zuweisung

| Operator | Beschreibung |
|----------|-------------|
| `=` | Zuweisung |
| `:=` | Kurzdeklaration |
| `+=` | Addieren und zuweisen |
| `-=` | Subtrahieren und zuweisen |
| `*=` | Multiplizieren und zuweisen |
| `/=` | Dividieren und zuweisen |
| `%=` | Modulo und zuweisen |
