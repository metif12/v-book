# Kommentare

## Zeilenkommentare

```v
// This is a line comment
x := 42 // Comment after code
```

## Blockkommentare

```v
/* This is a
   block comment */
```

## Dokumentationskommentare

```v
// add returns the sum of a and b.
fn add(a int, b int) int {
    return a + b
}
```
