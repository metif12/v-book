# 附录 A：关键字

V 有以下关键字：

| 关键字 | 描述 |
|---------|-------------|
| `as` | 类型转换 |
| `assert` | 断言 |
| `break` | 跳出循环 |
| `const` | 常量声明 |
| `continue` | 继续下一次迭代 |
| `defer` | 延迟执行 |
| `else` | else 分支 |
| `enum` | 枚举 |
| `false` | 布尔假 |
| `fn` | 函数声明 |
| `for` | 循环 |
| `go` | 启动 goroutine |
| `goto` | goto 语句 |
| `if` | 条件 |
| `import` | 模块导入 |
| `in` | 成员测试 |
| `interface` | 接口声明 |
| `is` | 类型检查 |
| `lock` | 互斥锁 |
| `match` | 模式匹配 |
| `module` | 模块声明 |
| `mut` | 可变 |
| `none` | 无值 |
| `or` | 错误处理 |
| `pub` | 公开可见性 |
| `return` | 从函数返回 |
| `struct` | 结构体声明 |
| `true` | 布尔真 |
| `type` | 类型声明 |
| `union` | 联合声明 |
| `unsafe` | 不安全代码 |
