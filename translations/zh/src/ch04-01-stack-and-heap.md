# 栈与堆

V 自动决定是在栈上还是堆上分配内存：

```v
fn main() {
    // 栈分配（小，固定大小）
    x := 42
    arr := [1, 2, 3]

    // 堆分配（大，动态）
    mut big := []int{}
    for i in 0 .. 1000 {
        big << i
    }

    println('${x} ${arr} ${big.len}')
}
```

## 栈

- 快速的分配和释放
- 编译时固定大小
- 作用域结束时自动释放

## 堆

- 动态大小
- 较慢的分配
- 由 GC 或自动释放管理
