# 附录 B：运算符

## 算术

| 运算符 | 描述 |
|----------|-------------|
| `+` | 加法 |
| `-` | 减法 |
| `*` | 乘法 |
| `/` | 除法 |
| `%` | 取模 |
| `**` | 幂运算 |

## 比较

| 运算符 | 描述 |
|----------|-------------|
| `==` | 等于 |
| `!=` | 不等于 |
| `<` | 小于 |
| `>` | 大于 |
| `<=` | 小于等于 |
| `>=` | 大于等于 |

## 逻辑

| 运算符 | 描述 |
|----------|-------------|
| `&&` | 逻辑与 |
| `\|\|` | 逻辑或 |
| `!` | 逻辑非 |

## 位运算

| 运算符 | 描述 |
|----------|-------------|
| `&` | 按位与 |
| `\|` | 按位或 |
| `^` | 按位异或 |
| `<<` | 左移 |
| `>>` | 右移 |

## 赋值

| 运算符 | 描述 |
|----------|-------------|
| `=` | 赋值 |
| `:=` | 短声明 |
| `+=` | 加后赋值 |
| `-=` | 减后赋值 |
| `*=` | 乘后赋值 |
| `/=` | 除后赋值 |
| `%=` | 取模后赋值 |
