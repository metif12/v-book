# 附录 D：标准库概览

V 的标准库包括：

| 模块 | 描述 |
|--------|-------------|
| `os` | 操作系统接口 |
| `io` | 输入/输出 |
| `strings` | 字符串工具 |
| `arrays` | 数组工具 |
| `math` | 数学函数 |
| `time` | 时间和日期 |
| `json` | JSON 编码/解码 |
| `http` | HTTP 客户端/服务器 |
| `db` | 数据库接口 |
| `rand` | 随机数生成 |
| `crypto` | 加密函数 |
| `encoding` | 编码工具 |
| `term` | 终端工具 |
| `sync` | 同步原语 |
| `v.ast` | V AST 操作 |
| `v.compiler` | 编译器工具 |
