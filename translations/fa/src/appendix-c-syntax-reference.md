# پیوست C: مرجع نحوی V

## توابع

```v
fn function_name(param1 int, param2 string) int {
    return param1
}
```

## struct ها

```v
struct StructName {
    field1 int
    field2 string
pub:
    public_field int
}
```

## enum ها

```v
enum EnumName {
    value1
    value2
}
```

## انواع جمع

```v
struct Type1 {}
struct Type2 {}

type SumType = Type1 | Type2
```

## اینترفیس‌ها

```v
interface InterfaceName {
    method_name() int
}
```
