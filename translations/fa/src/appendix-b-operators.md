# پیوست B: عملگرها

## ریاضی

| عملگر | توضیح |
|----------|-------------|
| `+` | جمع |
| `-` | تفریق |
| `*` | ضرب |
| `/` | تقسیم |
| `%` | باقیمانده |
| `**` | توان |

## مقایسه‌ای

| عملگر | توضیح |
|----------|-------------|
| `==` | مساوی |
| `!=` | نامساوی |
| `<` | کمتر از |
| `>` | بیشتر از |
| `<=` | کمتر یا مساوی |
| `>=` | بیشتر یا مساوی |

## منطقی

| عملگر | توضیح |
|----------|-------------|
| `&&` | AND منطقی |
| `\|\|` | OR منطقی |
| `!` | NOT منطقی |

## بیتی

| عملگر | توضیح |
|----------|-------------|
| `&` | AND بیتی |
| `\|` | OR بیتی |
| `^` | XOR بیتی |
| `<<` | شیفت چپ |
| `>>` | شیفت راست |

## انتساب

| عملگر | توضیح |
|----------|-------------|
| `=` | انتساب |
| `:=` | تعریف کوتاه |
| `+=` | جمع و انتساب |
| `-=` | تفریق و انتساب |
| `*=` | ضرب و انتساب |
| `/=` | تقسیم و انتساب |
| `%=` | باقیمانده و انتساب |
