# v.mod

فایل `v.mod` پروژه شما را توصیف می‌کند:

```v ignore
Module {
    name: 'my_project'
    description: 'My first V project'
    version: '0.1.0'
    license: 'MIT'
    dependencies: []
}
```

## فیلدها

| فیلد | توضیح |
|-------|-------------|
| `name` | نام پروژه (باید با نام دایرکتوری مطابقت داشته باشد) |
| `description` | توضیح کوتاه |
| `version` | نسخه معنایی |
| `license` | شناسه مجوز |
| `dependencies` | لیست نام بسته‌های VPM |
