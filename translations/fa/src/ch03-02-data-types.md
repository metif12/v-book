# انواع داده

## انواع عدد صحیح

| نوع | اندازه | بازه |
|------|------|-------|
| `i8` | 8 بیتی | -128 تا 127 |
| `i16` | 16 بیتی | -32,768 تا 32,767 |
| `i32` | 32 بیتی | -2^31 تا 2^31-1 |
| `i64` | 64 بیتی | -2^63 تا 2^63-1 |
| `int` | پلتفرم | معمولاً 64 بیتی |
| `u8` | 8 بیتی | 0 تا 255 |
| `u16` | 16 بیتی | 0 تا 65,535 |
| `u32` | 32 بیتی | 0 تا 2^32-1 |
| `u64` | 64 بیتی | 0 تا 2^64-1 |

## انواع اعشاری

| نوع | اندازه |
|------|------|
| `f32` | 32 بیتی |
| `f64` | 64 بیتی |

## انواع دیگر

- `bool` — `true` یا `false`
- `string` — رشته UTF-8
- `rune` — یک کاراکتر یونیکد (نام مستعار برای `u32`)
- `byte` — نام مستعار برای `u8`

## تبدیل نوع

```v
fn main() {
    a := 42
    b := f64(a)
    c := int(b)
    println('${a} ${b} ${c}')
}
```
