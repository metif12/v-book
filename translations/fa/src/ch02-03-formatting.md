# قالب‌بندی با v fmt

V یک قالب‌بند کد داخلی دارد:

```bash
v fmt -w .
```

پرچم `-w` تغییرات را به فایل‌ها بازنویسی می‌کند. بدون آن، قالب‌بند خروجی را به stdout چاپ می‌کند.

## مثال

قبل:

```v
fn main(){
println( 'hello' )
}
```

بعد از `v fmt`:

```v
fn main() {
    println('hello')
}
```
