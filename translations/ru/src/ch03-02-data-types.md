# Типы данных

## Целочисленные типы

| Тип | Размер | Диапазон |
|-----|--------|----------|
| `i8` | 8-бит | от -128 до 127 |
| `i16` | 16-бит | от -32 768 до 32 767 |
| `i32` | 32-бит | от -2^31 до 2^31-1 |
| `i64` | 64-бит | от -2^63 до 2^63-1 |
| `int` | платформозависимый | обычно 64-бит |
| `u8` | 8-бит | от 0 до 255 |
| `u16` | 16-бит | от 0 до 65 535 |
| `u32` | 32-бит | от 0 до 2^32-1 |
| `u64` | 64-бит | от 0 до 2^64-1 |

## Типы с плавающей точкой

| Тип | Размер |
|-----|--------|
| `f32` | 32-бит |
| `f64` | 64-бит |

## Другие типы

- `bool` — `true` или `false`
- `string` — строка UTF-8
- `rune` — один символ Unicode (псевдоним для `u32`)
- `byte` — псевдоним для `u8`

## Преобразование типов

```v
fn main() {
    a := 42
    b := f64(a)
    c := int(b)
    println('${a} ${b} ${c}')
}
```
