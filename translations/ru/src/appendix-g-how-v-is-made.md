# Приложение G: Как устроен V

V — это проект с открытым исходным кодом. Компилятор написан на самом V.

## Репозиторий

- GitHub: [vlang/v](https://github.com/vlang/v)
- Лицензия: MIT

## Сборка из исходного кода

```bash
git clone https://github.com/vlang/v
cd v
make
```
