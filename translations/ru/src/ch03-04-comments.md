# Комментарии

## Строчные комментарии

```v
// This is a line comment
x := 42 // Comment after code
```

## Блочные комментарии

```v
/* This is a
   block comment */
```

## Документационные комментарии

```v
// add returns the sum of a and b.
fn add(a int, b int) int {
    return a + b
}
```
