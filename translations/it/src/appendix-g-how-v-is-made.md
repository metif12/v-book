# Appendice G: Come è Fatto V

V è un progetto open-source. Il compilatore è scritto in V stesso.

## Repository

- GitHub: [vlang/v](https://github.com/vlang/v)
- Licenza: MIT

## Compilare dal sorgente

```bash
git clone https://github.com/vlang/v
cd v
make
```
