# Appendice B: Operatori

## Aritmetici

| Operatore | Descrizione |
|-----------|-------------|
| `+` | Addizione |
| `-` | Sottrazione |
| `*` | Moltiplicazione |
| `/` | Divisione |
| `%` | Modulo |
| `**` | Potenza |

## Confronto

| Operatore | Descrizione |
|-----------|-------------|
| `==` | Uguale |
| `!=` | Diverso |
| `<` | Minore di |
| `>` | Maggiore di |
| `<=` | Minore o uguale |
| `>=` | Maggiore o uguale |

## Logici

| Operatore | Descrizione |
|-----------|-------------|
| `&&` | AND logico |
| `\|\|` | OR logico |
| `!` | NOT logico |

## Bitwise

| Operatore | Descrizione |
|-----------|-------------|
| `&` | AND bitwise |
| `\|` | OR bitwise |
| `^` | XOR bitwise |
| `<<` | Shift a sinistra |
| `>>` | Shift a destra |

## Assegnazione

| Operatore | Descrizione |
|-----------|-------------|
| `=` | Assegnazione |
| `:=` | Dichiarazione breve |
| `+=` | Aggiungi e assegna |
| `-=` | Sottrai e assegna |
| `*=` | Moltiplica e assegna |
| `/=` | Dividi e assegna |
| `%=` | Modulo e assegna |
