# Appendice A: Parole Chiave

V ha le seguenti parole chiave:

| Parola Chiave | Descrizione |
|---------------|-------------|
| `as` | Type casting |
| `assert` | Asserzioni |
| `break` | Uscire dal ciclo |
| `const` | Dichiarazione di costante |
| `continue` | Passare alla prossima iterazione |
| `defer` | Esecuzione differita |
| `else` | Ramo else |
| `enum` | Enumerazione |
| `false` | Booleano falso |
| `fn` | Dichiarazione di funzione |
| `for` | Ciclo |
| `go` | Avviare goroutine |
| `goto` | Istruzione goto |
| `if` | Condizionale |
| `import` | Importazione modulo |
| `in` | Test di appartenenza |
| `interface` | Dichiarazione di interfaccia |
| `is` | Controllo di tipo |
| `lock` | Lock del mutex |
| `match` | Pattern matching |
| `module` | Dichiarazione di modulo |
| `mut` | Mutabile |
| `none` | Valore none |
| `or` | Gestione degli errori |
| `pub` | Visibilità pubblica |
| `return` | Ritorno da funzione |
| `struct` | Dichiarazione di struct |
| `true` | Booleano vero |
| `type` | Dichiarazione di tipo |
| `union` | Dichiarazione di union |
| `unsafe` | Codice unsafe |
