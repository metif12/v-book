# Commenti

## Commenti di riga

```v
// This is a line comment
x := 42 // Comment after code
```

## Commenti di blocco

```v
/* This is a
   block comment */
```

## Commenti di documentazione

```v
// add returns the sum of a and b.
fn add(a int, b int) int {
    return a + b
}
```
