# Appendice D: Panoramica della Standard Library

La standard library di V include:

| Modulo | Descrizione |
|--------|-------------|
| `os` | Interfaccia del sistema operativo |
| `io` | Input/output |
| `strings` | Utilità per le stringhe |
| `arrays` | Utilità per gli array |
| `math` | Funzioni matematiche |
| `time` | Data e ora |
| `json` | Codifica/decodifica JSON |
| `http` | Client/server HTTP |
| `db` | Interfaccia database |
| `rand` | Generazione di numeri casuali |
| `crypto` | Funzioni crittografiche |
| `encoding` | Utilità di codifica |
| `term` | Utilità del terminale |
| `sync` | Primitive di sincronizzazione |
| `v.ast` | Manipolazione AST V |
| `v.compiler` | Utilità del compilatore |
