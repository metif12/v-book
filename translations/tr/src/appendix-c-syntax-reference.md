# Ek C: V Sözdizimi Başvurusu

## Fonksiyonlar

```v
fn function_name(param1 int, param2 string) int {
    return param1
}
```

## Struct'lar

```v
struct StructName {
    field1 int
    field2 string
pub:
    public_field int
}
```

## Enum'lar

```v
enum EnumName {
    value1
    value2
}
```

## Toplam tipler

```v
struct Type1 {}
struct Type2 {}

type SumType = Type1 | Type2
```

## Interface'ler

```v
interface InterfaceName {
    method_name() int
}
```
