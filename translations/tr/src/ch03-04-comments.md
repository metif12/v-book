# Yorumlar

## Satır yorumları

```v
// This is a line comment
x := 42 // Comment after code
```

## Blok yorumları

```v
/* This is a
   block comment */
```

## Dokümantasyon yorumları

```v
// add returns the sum of a and b.
fn add(a int, b int) int {
    return a + b
}
```
