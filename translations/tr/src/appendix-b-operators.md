# Ek B: Operatörler

## Aritmetik

| Operatör | Açıklama |
|----------|-------------|
| `+` | Toplama |
| `-` | Çıkarma |
| `*` | Çarpma |
| `/` | Bölme |
| `%` | Mod |
| `**` | Üs |

## Karşılaştırma

| Operatör | Açıklama |
|----------|-------------|
| `==` | Eşit |
| `!=` | Eşit değil |
| `<` | Küçük |
| `>` | Büyük |
| `<=` | Küçük veya eşit |
| `>=` | Büyük veya eşit |

## Mantıksal

| Operatör | Açıklama |
|----------|-------------|
| `&&` | Mantıksal VE |
| `\|\|` | Mantıksal VEYA |
