# ضمیمہ A: کی ورڈز

V کے درج ذیل کی ورڈز ہیں:

| کی ورڈ | تفصیل |
|---------|-------------|
| `as` | ٹائپ کاسٹنگ |
| `assert` | اثبات |
| `break` | لوپ سے باہر نکلنا |
| `const` | مستقل تعریف |
| `continue` | اگلی تکرار پر جانا |
| `defer` | مؤخر شدہ عمل درآمد |
| `else` | متفرع شاخ |
| `enum` | اعداد و شمار |
| `false` | بولین غلط |
| `fn` | فنکشن تعریف |
| `for` | لوپ |
| `go` | goroutine پیدا کرنا |
| `goto` | goto بیان |
| `if` | مشروط |
| `import` | ماڈیول درآمد |
| `in` | رکنیت کی جانچ |
| `interface` | انٹرفیس تعریف |
| `is` | ٹائپ جانچ |
| `lock` | Mutex لاک |
| `match` | پیٹرن میچنگ |
| `module` | ماڈیول تعریف |
| `mut` | تبدیل پذیر |
| `none` | کوئی قدر نہیں |
| `or` | خرابی کی عاملہ کاری |
| `pub` | عوامی مرئیت |
| `return` | فنکشن سے واپسی |
| `struct` | struct تعریف |
| `true` | بولین سچ |
| `type` | ٹائپ تعریف |
| `union` | یونین تعریف |
| `unsafe` | غیر محفوظ کوڈ |
