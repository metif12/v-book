# ضمیمہ C: V نحو کا حوالہ

## فنکشنز

```v
fn function_name(param1 int, param2 string) int {
    return param1
}
```

## structs

```v
struct StructName {
    field1 int
    field2 string
pub:
    public_field int
}
```

## enums

```v
enum EnumName {
    value1
    value2
}
```

## سم ٹائپس

```v
struct Type1 {}
struct Type2 {}

type SumType = Type1 | Type2
```

## انٹرفیسز

```v
interface InterfaceName {
    method_name() int
}
```

## ماڈیولز

```v ignore
module module_name

pub fn public_function() {
    // ...
}
```
