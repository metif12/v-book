# v fmt کے ساتھ فارمیٹنگ

V میں ایک بلٹ اِن کوڈ فارمیٹر ہے:

```bash
v fmt -w .
```

`-w` فلگ تبدیلیوں کو فائلوں میں واپس لکھتا ہے۔ اس کے بغیر، فارمیٹر stdout پر پرنٹ کرتا ہے۔

## مثال

پہلے:

```v
fn main(){
println( 'hello' )
}
```

`v fmt` کے بعد:

```v
fn main() {
    println('hello')
}
```
