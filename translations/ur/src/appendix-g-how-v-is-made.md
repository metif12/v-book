# ضمیمہ G: V کیسے بنایا گیا

V ایک اوپن سورس پروجیکٹ ہے۔ کمپائلر V خود میں لکھا گیا ہے۔

## ریپوزٹری

- GitHub: [vlang/v](https://github.com/vlang/v)
- لائسنس: MIT

## ماخذ سے بنانا

```bash
git clone https://github.com/vlang/v
cd v
make
```
