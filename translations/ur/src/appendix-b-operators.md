# ضمیمہ B: آپریٹرز

## حسابی

| آپریٹر | تفصیل |
|----------|-------------|
| `+` | جمع |
| `-` | تفریق |
| `*` | ضرب |
| `/` | تقسیم |
| `%` | موڈیولو |
| `**` | طاقت |

## موازنہ

| آپریٹر | تفصیل |
|----------|-------------|
| `==` | برابر |
| `!=` | غیر برابر |
| `<` | کم از کم |
| `>` | زیادہ از زیادہ |
| `<=` | کم از کم یا برابر |
| `>=` | زیادہ از زیادہ یا برابر |

## منطقی

| آپریٹر | تفصیل |
|----------|-------------|
| `&&` | منطقی AND |
| `\|\|` | منطقی OR |
| `!` | منطقی NOT |

## بٹ وائز

| آپریٹر | تفصیل |
|----------|-------------|
| `&` | بٹ وائز AND |
| `\|` | بٹ وائز OR |
| `^` | بٹ وائز XOR |
| `<<` | بائیں شفٹ |
| `>>` | دائیں شفٹ |

## اسائنمنٹ

| آپریٹر | تفصیل |
|----------|-------------|
| `=` | اسائنمنٹ |
| `:=` | مختصر تعریف |
| `+=` | جمع اور اسائن کریں |
| `-=` | تفریق اور اسائن کریں |
| `*=` | ضرب اور اسائن کریں |
| `/=` | تقسیم اور اسائن کریں |
| `%=` | موڈیولو اور اسائن کریں |
