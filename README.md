# The V Programming Language Book

A comprehensive book for the [V programming language](https://vlang.io), inspired by [The Rust Book](https://doc.rust-lang.org/book/).

## Project Goals

- **Comprehensive**: Cover V from installation to advanced topics
- **Tested**: Every code example compiled and run in CI
- **Accessible**: Available in 16 languages including Farsi (fa), Arabic (ar), and Urdu (ur)
- **Community-driven**: Open to contributions from the V community
- **Modern**: Targets V 0.5.2+

## The Site

The book is a static site generated by V itself:

```bash
v run site                  # build the whole site into dist/
v run site serve            # build, then preview at http://localhost:8090/v-book/
```

`dist/` holds the whole book — English at the root, every translation under its
own language directory — plus `sitemap.xml`, `robots.txt`, a per-language search
index, and a `404.html`. It deploys to GitHub Pages as-is, no server required.

What the site does:

- **Search** — `Ctrl`/`Cmd`+`K` focuses the search box, `/` does the same, and
  the results come from a full text index that ships with the page, so nothing
  leaves the browser and any static host works.
- **The tour's layout** — V logo, dark navy bar, table of contents on the left,
  and one centred reading column. Light and dark themes, both resolved from the
  system until the reader says otherwise.
- **Code blocks** — V blocks are highlighted by CodeMirror with a copy button;
  shell blocks show the commands.
- **Right-to-left** — the Arabic, Persian and Urdu translations switch the
  whole shell, and each language keeps the reader on the same page.

## Quick Start

### Prerequisites

- [V](https://vlang.io) 0.5.2+

### Build the book

```bash
v run site
```

### Preview

```bash
v run site serve
```

### Test code examples

```bash
v run tools/code_check.vsh        # src/ and every translation
v run tools/code_check.vsh src    # the English source only
```

### Validate book structure

```bash
v run tools/validate.vsh
```

### Run tests

```bash
v test .
```

## Code Examples

Code examples follow these conventions:

- `v` — compiled and run in CI
- `v ignore` — not compiled (pseudocode, incomplete examples)
- `v no_run` — compiled but not run (blocking examples)

Every code block is self-contained and tested in CI. `tools/code_check.vsh`
extracts all `v` blocks and runs each one through `v run`.
