Testing with v test

V has a built-in testing framework. Create a file ending in _test.v:

fn add(a int, b int) int {
    return a + b
}

fn test_add() {
    assert add(2, 3) == 5
    assert add(-1, 1) == 0
}

Run tests:

v test .

Test functions

Test functions start with test_ and take no arguments:

fn test_something() {
    assert true
}

Assertions

Use assert to check conditions:

fn test_math() {
    assert 1 + 1 == 2
    assert 2 * 3 == 6
}
