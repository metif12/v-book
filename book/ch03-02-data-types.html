Other types

  • bool — true or false
  • string — UTF-8 string
  • rune — single Unicode character (alias for u32)
  • byte — alias for u8

Type conversion

fn main() {
    a := 42
    b := f64(a)
    c := int(b)
    println('${a} ${b} ${c}')
}
