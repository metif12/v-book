Formatting with v fmt

V has a built-in code formatter:

v fmt -w .

The -w flag writes changes back to files. Without it, the formatter prints to stdout.

Example

Before:

fn main(){
println( 'hello' )
}

After v fmt:

fn main() {
    println('hello')
}
