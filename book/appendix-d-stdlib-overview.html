Appendix D: Standard Library Overview

V’s standard library includes:

ModuleDescription
osOperating system interface
ioInput/output
stringsString utilities
arraysArray utilities
mathMathematical functions
timeTime and date
jsonJSON encoding/decoding
httpHTTP client/server
dbDatabase interface
randRandom number generation
cryptoCryptographic functions
encodingEncoding utilities
termTerminal utilities
syncSynchronization primitives
v.astV AST manipulation
v.compilerCompiler utilities
