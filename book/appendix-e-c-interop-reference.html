Appendix E: V and C Interop Reference

Including C code

#include "myheader.h"

C flags

#flag -lm
#flag -I/path/to/include

Calling C functions

fn C.my_c_function(int) int

Exporting V functions

@[export: 'my_v_function']
fn my_v_function() {
    // ...
}

Shared libraries

v -shared -o libmylib.so mylib.v
