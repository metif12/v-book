# Goals

## Primary Goal

Create a comprehensive, Rust Book-quality resource for the V programming language that is:
- **Complete**: Covers V from installation to advanced topics
- **Tested**: Every code example is compiled and run in CI
- **Accessible**: Available in 16 languages including Farsi
- **Maintainable**: Community-driven, easy to update

## Secondary Goals

### Educational
- Teach V to programmers coming from other languages
- Provide a structured learning path
- Include practical, real-world examples
- Build confidence through hands-on projects

### Community
- Foster a community of V learners and contributors
- Provide clear contribution guidelines
- Support community translations
- Create a resource that grows with V

### Technical
- Maintain high code quality standards
- Ensure all examples work with V 0.5.2+
- Support RTL languages properly
- Enable easy local development

## Success Metrics

- [ ] All 20 chapters + 7 appendices written
- [ ] All code examples pass CI
- [ ] At least 5 non-English translations started
- [ ] Book builds successfully with mdBook
- [ ] Positive community feedback

## Non-Goals

- **Replacing official documentation**: This is a learning resource, not a reference
- **Covering every V feature**: Focus on what learners need, not exhaustive coverage
- **Interactive execution**: That's what tour-of-v provides
- **Video content**: Text-based book only
